# Security Policy

## Supported Versions

Only the latest commit on `main` is supported with security updates.

## Reporting a Vulnerability

**Do not open a public issue.** Security vulnerabilities should be reported privately.

Please send details to the project maintainer via the GitHub Security Advisory form:

https://github.com/yassirpersonelle-oss/oss-toolkit/security/advisories/new

Expected response time: within 48 hours.

## Scope

All 30+ tools in this monorepo are in scope. Third-party dependencies used by the tools at runtime are also in scope.

## Out of Scope

- Issues in user-created tool implementations (you write it, you secure it)
- Social engineering attacks
- DoS attacks
